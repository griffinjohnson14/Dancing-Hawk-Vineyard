# Adding an Update

1. Go to **github.com/griffinjohnson14/Dancing-Hawk-Vineyard**

2. Click the **images** folder.

3. Click **Add file**, then **Upload files**.

4. Drag your photos in. Name them with dashes and no spaces, like `harvest-morning.jpg`

5. Click **Commit changes**.

6. Write down the photo file names exactly as they appear, capital letters included.

7. Go back to the main page and click **posts.js**

8. Click the pencil icon in the top right.

9. Scroll to the bottom. Copy the blank block between the two dashed lines.

10. Paste it just under the line that says `const posts = [`

11. On the **title** line, type your headline between the quote marks.

12. On the **date** line, type the date between the quote marks, like `2026-08-14`

13. On the **photos** lines, type one file name between each pair of quote marks:

        photos: [
            "harvest-morning.jpg",
            "new-trellis-posts.jpg"
        ],

    There are two slots to start. Add another line for each extra photo, or delete one
    if you only have a single photo. Each line needs a comma at the end except the last
    — an extra comma on the end is harmless, a missing one in the middle is not.

14. On the **body** lines, type your update between the quote marks. One line per paragraph.

15. Click **Commit changes**.

16. Wait one minute, then open **dancinghawkvineyard.com** to see it.

---

Something not right? See **HOW-TO-ADD-A-POST.md** for more detail and how to undo a mistake.
